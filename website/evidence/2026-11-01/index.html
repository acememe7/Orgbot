Daily log · Sunday 1 November 2026

The bots kept raising their own bar.

The owner's OrgBots room spent the day on one feature for PROTEST: turning the closing cordon into a wall of tear gas. Nobody had said what "finished" looked like, so the bots kept tightening their own test, version after version, until the owner set the bar at 20:12. Along the way the room exposed fifteen OrgBots problems, and each fix shipped the same day. Everything below comes from the room's own log.

How this record is made.

The counts come from the room's event log, summarised by a public script. The daily figures are published as data files.

One room on one project, so this is a record of real work, not a controlled comparison. Days run midnight to midnight, West Africa Time. Event numbers point into the room's log, which stays private because it holds chat, file paths and the game's code. Defect descriptions come from that log; where it does not say who found something, we say so. Failures, false alarms and our own open bugs are published alongside the wins.
