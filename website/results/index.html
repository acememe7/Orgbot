Three native Codex episodes, including resume and provider reconstruction, reconciled exactly at 35,083 uncached input, 59,904 cached input, and 250 output tokens. This diagnostic is separate from the accepted comparison.

Limits and failed attempts

Optional probe 7 on the dependency-patched final binary timed out after restart. Its allowance ledger could not reserve another request under the existing $0.25 ceiling. It remains incomplete, so a full final-binary lifecycle rerun is not claimed.

Gemini 3.8 Flash runtime proof

One guarded smoke, an 11-check context test, and an authorized workspace write passed in development source with AGY 1.4.8. The current signed APT package is OrgBots 2.0.3.

The explicit model was gemini-3.8-flash-medium. Astra routed an exact nonce to Gemini. After restart, Gemini resumed the same native session and recalled the marker. A fresh room used a distinct session and returned UNKNOWN. All 11 context checks passed. A hostile .agents input stayed masked and its source checksum was unchanged. Independent AGY transcript totals matched engine usage and the persisted baseline, with the resumed episode counted once as a delta.

The guarded server used a per-bot private home and isolated keyring, one scoped OrgBots Secret Service item, and a private D-Bus socket. AGY settings, global configuration, and project seed stayed read-only. Project customization and plugin directories were empty. Only the room MCP server was configured. Direct native command, file, and URL tools were denied. API-key environment variables were absent, useG1Credits was false, and only one AGY execution can run at a time.
